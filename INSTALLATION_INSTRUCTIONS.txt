🎯 QUICK START (5 MINUTES)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. EXTRACT THE ARCHIVE
   ───────────────────
   tar -xzf focusflow-production-complete.tar.gz
   cd focusflow-production

2. RUN SETUP SCRIPT
   ───────────────────
   ./setup.sh
   
   This will:
   - Check prerequisites (Docker, Node.js)
   - Create .env file
   - Start all services with Docker Compose
   - Set up database
   
3. ACCESS THE APP
   ───────────────
   🌐 Web App:      http://localhost:3000
   🔧 API:          http://localhost:4000
   💾 Database UI:  http://localhost:8080
   📊 Redis UI:     http://localhost:8081

4. CREATE ACCOUNT
   ───────────────
   Open http://localhost:3000 and click "Sign Up"
   Or use the API (see QUICKSTART.md)

   cd scripts/migrations
   node import-mvp-data.js --email your@email.com --password YourPassword

   - Deploy with provided Dockerfiles

OPTION 5: Manual VPS (DigitalOcean, Linode, etc.)
   - Install Docker
   - Run docker-compose
   - Configure Nginx

🐛 TROUBLESHOOTING
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

PROBLEM: Port already in use
SOLUTION: Change ports in docker-compose.yml or kill process using port

PROBLEM: Database connection failed
SOLUTION: Wait 10 seconds, restart postgres: docker-compose restart postgres

PROBLEM: Cannot connect to API
SOLUTION: Check API logs: docker-compose logs api

PROBLEM: Frontend not loading
SOLUTION: Rebuild web: docker-compose build web && docker-compose up -d web

See QUICKSTART.md "Troubleshooting" section for more.
